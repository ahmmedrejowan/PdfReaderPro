## Возможности

- **Просмотр PDF** — плавный рендеринг с масштабированием, прокруткой и навигацией по страницам
- **12 инструментов PDF** — объединение, разделение, сжатие, поворот, изменение порядка, удаление страниц, добавление номеров страниц, водяных знаков, блокировка/разблокировка, PDF в изображения, изображения в PDF
- **Закладки** — сохранение и управление закладками внутри документов
- **Оглавление** — навигация с использованием структуры документа
- **Поиск** — полнотекстовый поиск внутри документов
- **Автопрокрутка** — чтение без рук с регулируемой скоростью
- **Управление файлами** — просмотр, поиск, сортировка и организация PDF
- **Недавние и избранное** — быстрый доступ к вашим файлам
- **Дизайн Material 3** — современный интерфейс с тёмной темой и динамическими цветами
- **100% офлайн** — полная конфиденциальность, без рекламы, без отслеживания

## Архитектура

PDF Reader Pro следует принципам **Clean Architecture** с паттерном **MVVM**:

```text
app/
├── data/                      # Слой данных
│   ├── local/
│   │   ├── database/          # База данных Room
│   │   └── preferences/       # Настройки DataStore
│   └── repository/            # Реализации репозиториев
│
├── domain/                    # Слой домена
│   ├── model/                 # Модели домена
│   └── repository/            # Интерфейсы репозиториев
│
├── presentation/              # Слой представления (UI)
│   ├── components/            # Переиспользуемые компоненты Compose
│   ├── navigation/            # Граф навигации
│   ├── screens/               # Экраны UI
│   │   ├── home/              # Главный экран с браузером файлов
│   │   ├── reader/            # Просмотрщик PDF
│   │   ├── tools/             # Инструменты PDF
│   │   └── settings/          # Настройки
│   └── theme/                 # Темизация Material 3
│
├── di/                        # Внедрение зависимостей Koin
└── util/                      # Утилиты
```

### Технологический стек

- **UI-фреймворк**: Jetpack Compose (100% Compose UI)
- **Язык**: Kotlin (100%)
- **Архитектура**: MVVM + Clean Architecture
- **Внедрение зависимостей**: Koin
- **База данных**: Room
- **Асинхронность**: Kotlin Coroutines + StateFlow
- **Навигация**: Jetpack Navigation Compose
- **Рендеринг PDF**: Собственный PDF.js WebView
- **Обработка PDF**: iText 7
- **Загрузка изображений**: Coil
- **Хранение данных**: DataStore Preferences

## Требования

- **Минимальный SDK**: API 24 (Android 7.0 Nougat)
- **Целевой SDK**: API 36 (Android 16)
- **Compile SDK**: API 36
- **Gradle**: 9.4.0
- **AGP**: 9.1.0
- **Kotlin**: 2.3.10
- **Java**: 21

### Разрешения

- `READ_EXTERNAL_STORAGE` / `READ_MEDIA_DOCUMENTS` — доступ к PDF-файлам
- `WRITE_EXTERNAL_STORAGE` — сохранение обработанных PDF (Android 9 и ниже)
- `INTERNET` — опционально, только для проверки обновлений в приложении

**Примечание:** Это приложение не собирает и не передаёт какие-либо пользовательские данные.

## Сборка и запуск

Чтобы собрать и запустить проект, выполните следующие шаги:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ahmmedrejowan/PdfReaderPro.git
   ```
2. Откройте проект в Android Studio.
3. Синхронизируйте проект с файлами Gradle.
4. Подключите ваше Android-устройство или запустите эмулятор.
5. Нажмите кнопку «Run» в Android Studio, чтобы собрать и запустить приложение.
