## Возможности

- **Просмотр PDF** — плавный рендеринг с масштабированием, прокруткой и навигацией по страницам
- **12 инструментов PDF** — объединение, разделение, сжатие, поворот, изменение порядка, удаление страниц, добавление номеров страниц, водяных знаков, блокировка/разблокировка, PDF в изображения, изображения в PDF
- **Закладки** — сохранение и управление закладками внутри документов
- **Оглавление** — навигация с использованием структуры документа
- **Поиск** — полнотекстовый поиск внутри документов
- **Автопрокрутка** — чтение без рук с регулируемой скоростью
- **Управление файлами** — просмотр, поиск, сортировка и организация PDF
- **Недавние и избранное** — быстрый доступ к вашим файлам
- **Дизайн Material 3** — современный интерфейс с тёмной темой и динамическими цветами
- **100% офлайн** — полная конфиденциальность, без рекламы, без отслеживания

## Архитектура

PDF Reader Pro следует принципам **Clean Architecture** с паттерном **MVVM**:

```
app/
├── data/                      # Data layer
│   ├── local/
│   │   ├── database/          # Room database
│   │   └── preferences/       # DataStore preferences
│   └── repository/            # Repository implementations
│
├── domain/                    # Domain layer
│   ├── model/                 # Domain models
│   └── repository/            # Repository interfaces
│
├── presentation/              # Presentation layer (UI)
│   ├── components/            # Reusable Compose components
│   ├── navigation/            # Navigation graph
│   ├── screens/               # UI screens
│   │   ├── home/              # Home with file browser
│   │   ├── reader/            # PDF reader
│   │   ├── tools/             # PDF tools
│   │   └── settings/          # Settings
│   └── theme/                 # Material 3 theming
│
├── di/                        # Koin dependency injection
└── util/                      # Utilities
```

### Технологический стек

- **UI-фреймворк**: Jetpack Compose (100% Compose UI)
- **Язык**: Kotlin (100%)
- **Архитектура**: MVVM + Clean Architecture
- **Внедрение зависимостей**: Koin
- **База данных**: Room
- **Асинхронность**: Kotlin Coroutines + StateFlow
- **Навигация**: Jetpack Navigation Compose
- **Рендеринг PDF**: Собственный PDF.js WebView
- **Обработка PDF**: iText 9
- **Загрузка изображений**: Coil
- **Хранение данных**: DataStore Preferences

## Требования

- **Минимальный SDK**: API 24 (Android 7.0 Nougat)
- **Целевой SDK**: API 37
- **Compile SDK**: API 37
- **Gradle**: 9.8.0
- **AGP**: 9.4.1
- **Kotlin**: 2.4.20
- **Java**: 21

### Разрешения

- `READ_EXTERNAL_STORAGE` / `READ_MEDIA_DOCUMENTS` — доступ к PDF-файлам
- `WRITE_EXTERNAL_STORAGE` — сохранение обработанных PDF (Android 9 и ниже)
- `INTERNET` — опционально, только для проверки обновлений в приложении

**Примечание:** Это приложение не собирает и не передаёт какие-либо пользовательские данные.

## Сборка и запуск

Чтобы собрать и запустить проект, выполните следующие шаги:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ahmmedrejowan/PdfReaderPro.git
   ```
2. Откройте проект в Android Studio.
3. Синхронизируйте проект с файлами Gradle.
4. Подключите ваше Android-устройство или запустите эмулятор.
5. Нажмите кнопку «Run» в Android Studio, чтобы собрать и запустить приложение.

## Возможности

PDF Reader Pro работает с TalkBack и системным размером шрифта. Полная поддержка программ чтения с экрана появится в первой версии после 2.6.0.

| Область                                       | Поддержка                                                                                        |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Чтение с экрана (TalkBack) | ✅ У всех кнопок есть подписи; параметры сообщают своё состояние; заголовки и живые объявления    |
| Озвучивание PDF                               | ✅ Текст и ссылки PDF (кроме сканов, состоящих только из изображений)          |
| Размер шрифта                                 | ✅ Следует системному размеру шрифта                                                              |
| Тёмные и контрастные темы                     | ✅ Тёмная, Чёрная (AMOLED) и Сепия                                             |
| Жесты                                         | ⚠️ Порядок страниц меняется только перетаскиванием; у ползунка страниц есть «Перейти к странице» |
| Switch Access и клавиатура                    | ❔ Ещё не проверено                                                                               |

Подробности есть на [странице вики о специальных возможностях](https://github.com/ahmmedrejowan/PdfReaderPro/wiki/Accessibility). Что-то неудобно? Напишите в [обсуждении специальных возможностей](https://github.com/ahmmedrejowan/PdfReaderPro/discussions/114).

## История изменений

### v2.6.0 (2026-10-23)

- «Вернуться на страницу»: после перехода кнопка возвращает на прежнюю страницу (#88)
- Инструменты PDF открываются прямо из читалки для открытого документа (#105)
- Сохранение цветов изображений в тёмной и чёрной темах (#87)
- Настройка, чтобы скрывать файлы и папки, имя которых начинается с точки (#6)
- Короткие документы показываются по центру экрана (#105)
- Исправлено: первая страница и переходы больше не уходят под верхнюю панель (#105)
- Исправлено: подписанные файлы больше не пропадают из выбора файлов в других приложениях
- Исправлены счётчики для одного элемента («1 страница»), а «Назад» закрывает боковые панели в альбомной ориентации
- Исправлена кнопка «Повторить» на экране объединения на всех языках

### v2.5.0 (2026-10-09)

- Подпись документов: нарисуйте, введите или выберите изображение подписи в режиме чтения или в «Инструментах»
- Подписи хранятся для каждого документа, управляются в одном окне и записываются в файл или в копию
- Переводы на бенгальский, русский, немецкий, испанский, французский, итальянский, португальский, турецкий, польский, ирландский и японский (#91, #93, #95, #98)
- Выбор языка приложения в настройках, на любой версии Android
- Переводчики, например Google Переводчик, появляются в меню выделения текста (#78)
